Happy 1st Monthsary, Wifey 💗 — website
========================================

HOW TO OPEN
-----------
Double-click "index.html" — that's it!

HOW TO ADD YOUR PHOTOS  (most important step)
----------------------------------------------
Your photos could not be copied from the chat automatically, so save them
into the "assets" folder with these exact names:

    assets\photo1.jpg     -> "Two halves, one whole heart" (big heart photo on top)
    assets\photo2.jpg     -> "Hi My Wifey" drawing
    assets\photo3.jpg     -> grumpy cat drawing
    assets\photo4.jpg     -> LOVE ONES pinky-promise drawing

.jpg, .png and .jpeg all work — the site automatically tries each one.
Until a photo is added, the slot shows a pink placeholder with the
expected filename, so the page still looks good.

HOW TO EDIT (all in js/script.js, top of the file)
---------------------------------------------------
- CONFIG.photos     -> change captions or add/remove photos.

"since September 5, 2026" is plain text in index.html — edit it there
if the date ever changes. (The days/hours/minutes/seconds timer was
removed on request.)

HOW TO EDIT THE LETTERS (in index.html)
----------------------------------------
- First letter  = your original message (light and sweet)
- Second letter = the deeper version (hidden behind the
                  "Read the deeper one" button)

MUSIC (optional)
----------------
Put a file named "assets\music.mp3" and the ♪ button in the top-right
will play it. Without it, the button just stays muted.

OTHER EDITABLE TEXT (index.html)
--------------------------------
- Couple names: search for "Koni" and "Yana" (nav, footer, closing)
- Hero subtitle, section titles, reason cards, captions

FILES
-----
    index.html      the whole page
    css/style.css   design / animations
    js/script.js    counter, gallery, letters, hearts, music
    assets/         put your photos (and optional music.mp3) here
